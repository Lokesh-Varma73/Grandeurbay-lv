
# GrandeurBay - Premium Fashion & Luxury Store

![GrandeurBay](https://images.unsplash.com/photo-1441986300917-64674bd600d8?q=80&w=2070&auto=format&fit=crop)

## 🌟 Overview

GrandeurBay is a modern e-commerce platform built with React and TypeScript, offering a premium shopping experience for fashion and luxury items. This project showcases a fully responsive design with features like product browsing, cart management, wishlist functionality, and user authentication.

## 🚀 Technologies Used

### Core Technologies
- **React 18** - Modern UI library for building component-based interfaces
- **TypeScript** - Strongly typed JavaScript for enhanced code quality
- **Vite** - Next-generation frontend build tool with lightning-fast HMR

### UI & Styling
- **Tailwind CSS** - Utility-first CSS framework for rapid UI development
- **Shadcn/UI** - Beautiful, accessible component library built on Radix UI
- **Lucide React** - Modern icon library with clean, consistent design

### State Management & Data Fetching
- **React Query** - Powerful data synchronization for React applications
- **Context API** - React's built-in state management for app-wide state

### Form Handling
- **React Hook Form** - Performant form validation with minimal re-renders
- **Zod** - TypeScript-first schema validation library

### Routing
- **React Router** - Client-side routing with support for nested routes

### Additional Libraries
- **Sonner** - Toast notifications with a clean, minimal design
- **date-fns** - Modern JavaScript date utility library
- **Embla Carousel** - Extensible carousel component for image galleries

## 🔧 Getting Started

### Prerequisites
- Node.js (v16.0 or higher)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to project directory
cd grandeurbay-lv

# Install dependencies
npm install
# or
yarn install

# Start development server
npm run dev
# or
yarn dev

#if they is any error run thos command and then run (npm run dev)
rm -r -force node_modules/.vite
```

After running these commands, open your browser and navigate to:
```
http://localhost:8080
```

## 📱 Features

- **Responsive Design** - Optimized for all device sizes from mobile to desktop
- **Product Browsing** - Browse products by category with filtering options
- **Product Details** - View detailed product information with image galleries
- **Shopping Cart** - Add products to cart with size/color selection
- **Wishlist** - Save products for later consideration
- **User Authentication** - Sign up, sign in, and password recovery
- **User Account** - Manage orders, wishlist, and account settings
- **Theme Switching** - Toggle between light and dark mode
